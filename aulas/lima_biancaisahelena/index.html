Códigos

Comentário:

Caixas

"section" divide o site em partes

"div" funciona como uma caixa para organizar os elementos

"class" especificar um elemento

CSS

  • color: muda a cor do texto
  • background-color: muda a cor do fundo
  • font-size: tamanho da fonte
  • font-family: tipo da fonte
  • text-align: alinhamento
  • border: cria uma borda
  • border-radius: arredonda as bordas
  • padding: espaço interno
  • margin: espaço externo

Imagens

A tag "img" insere imagens

O atributo src informa onde está a imagem
